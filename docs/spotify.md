# Spotify: любимые песни

В исходниках версии 1.1 добавлена кнопка сердца рядом с громкостью на музыкальной панели. Она появляется при выборе медиасессии Spotify в раскрытой и средней панели. Нажатие в средней панели сохраняет её размер. Пустое сердце добавляет текущую песню в «Любимые», заполненное — удаляет. В опубликованный релиз 1.0 эта возможность не входит.

## Однократное подключение

1. Откройте **Настройки → Виджеты → Музыка и звук → Spotify**.
2. Войдите в [Spotify Developer Dashboard](https://developer.spotify.com/dashboard) своим аккаунтом Premium и создайте личное приложение NabyScape. Выберите Web API.
3. Укажите адрес возврата **`http://127.0.0.1:43821/callback`** без изменений и сохраните приложение. Условия Spotify принимаете самостоятельно.
4. Скопируйте **Client ID** в настройки NabyScape. Пароль и Client Secret не нужны. Поле Client ID по умолчанию скрыто; глазок показывает его временно. При уходе из окна значение снова скрывается.
5. Нажмите **Подключить Spotify** и самостоятельно разрешите в браузере чтение текущего трека и чтение/изменение библиотеки. При отказе в доступе проверьте список пользователей приложения в Developer Dashboard.

Кнопка работает с треком, который одновременно выбран в Windows и воспроизводится в Spotify. Если название, исполнитель или длительность не совпадают, сердце временно недоступно: программа не подбирает песню приблизительным поиском. При смене трека старый ответ игнорируется.

Токен для восстановления подключения хранится в диспетчере учётных данных Windows; в файле профиля остаются публичный Client ID и признак подключения. Кнопка **Отключить Spotify** останавливает запросы и удаляет сохранённый доступ. Настройки и заметки при этом сохраняются.

Интеграция использует [Authorization Code с PKCE](https://developer.spotify.com/documentation/web-api/tutorials/code-pkce-flow), [текущий трек](https://developer.spotify.com/documentation/web-api/reference/get-the-users-currently-playing-track), [проверку библиотеки](https://developer.spotify.com/documentation/web-api/reference/check-library-contains) и [сохранение элементов](https://developer.spotify.com/documentation/web-api/reference/save-library-items). Ограничения личных приложений описаны в [правилах Development Mode](https://developer.spotify.com/documentation/web-api/tutorials/february-2026-migration-guide).
