# NabyScape 1.0 — первый релиз русской версии

Самостоятельный релиз форка на основе NabyScape 2.26.1. Версия приложения — **1.0.0**. Ранее изменения распространялись локально как `2.26.1-ru.*`.

## Что изменено относительно оригинала

- Русифицированы настройки, меню, подсказки, виджеты, уведомления, установщик и функции помощника.
- Добавлены светлая и тёмная темы настроек, новый логотип, скруглённое окно, поиск в шапке и общий сворачиваемый предпросмотр.
- Настройки функций панели собраны в раздел «Виджеты».
- Убрано ограничение автоматического поиска текстов песен на английский, японский и корейский; сохранены транскрибирование и локальный LRC.
- Исправлено переключение вкладок колесом; добавлен выбор кругового перехода.
- Добавлены исключения автоматического скрытия для выбранных приложений.
- В простое свёрнутая панель показывает время; активные таймеры и секундомер отображаются в ней счётчиком.
- Добавлена библиотека заметок: раскрывающиеся карточки, заголовки, автоматическое название по первой фразе, выбор группы и корзина без раскрытия карточки.
- Заголовок и текст черновика синхронизируются между настройками, панелью и отдельным окном заметок.
- Добавлен раздел задач; исправлен откат добавления и удаления при ошибке сохранения и область нажатия галочек.
- Обновлены поиск, статусы текстов песен и отображение версии; восстановлена проверка всех 20 разделов настроек.
- Обновления оригинального проекта заблокированы, чтобы не заменять изменения форка.

## Скачать

- **NabyScape-win-x64-Setup.exe** — установщик для Windows 10/11 x64.
- **NabyScape-win-x64-Portable.zip** — запуск без установки; профиль остаётся в `%LOCALAPPDATA%\NabyScape`.
- **NabyScape-Notices.zip** — лицензия MIT и уведомления о сторонних компонентах.
- **SHA256SUMS** — контрольные суммы файлов релиза.

Среда .NET включена. ARM64 в этом релизе не публикуется. Сборка не имеет цифровой подписи.

## Обновление с нашей сборки

Завершите NabyScape через область уведомлений и запустите новый установщик. Удалять настройки, заметки и задачи не нужно. Перед обновлением можно сохранить копию `%LOCALAPPDATA%\NabyScape`.

Релиз не включает API-ключи, личный профиль и загруженные модели помощника. ИИ настраивается отдельно. Музыка зависит от поддержки Windows со стороны проигрывателя, тексты песен — от наличия у выбранных источников.

Поведение панели при разделённом экране ещё будет дорабатываться. Нативное размытие Mica/Acrylic не используется в прозрачном окне настроек с настоящим скруглённым контуром.

Оригинальный проект: [BillyNabil/nabyscape](https://github.com/BillyNabil/nabyscape). Лицензия MIT и уведомления автора сохранены.
